# rv-runtime

[![REUSE status](https://api.reuse.software/badge/github.com/rivosinc/rv-runtime)](https://api.reuse.software/info/github.com/rivosinc/rv-runtime)

## rv-runtime-generator

This is a tool that can be used to generate the runtime for any bare-metal
RISC-V component.

## rv-runtime-test

This is a test Rust application built using the runtime generated by the
generator.
